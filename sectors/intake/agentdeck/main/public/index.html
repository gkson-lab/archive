Sign in to agentdeck

agentdeck runs agents with your Claude account. It uses Claude Code's own sign-in, so your password and token never pass through this app.

The claude command isn't installed. Install Claude Code from a terminal, then click "I've signed in": 
curl -fsSL https://claude.ai/install.sh | bash
